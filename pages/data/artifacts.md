# Artifact

![RunのArtifactsタブで音声ファイルを開いた画面](/images/data-artifacts-run.png)

Artifactは、Projectに保存したファイルです。学習の重み、推論で作った音声、評価結果のjsonl、データセットの本体など、記録したいファイルはすべてArtifactとして保存します。

Artifactは、Projectで選んだ保存先（ファイルシステムかS3互換ストレージ）に置かれます。SDKやworkerはAPIを経由して読み書きするため、ストレージの認証情報を配る必要はありません。保存先の設定は[保存先の設定](/data/storage)を参照してください。

## こんなときに向いています

- 学習で作った重みやcheckpointを、Runと結び付けて残したい
- 推論で作った音声を、ブラウザで波形を見ながら聴きたい
- Projectのどこかに保存した音声を、パスや種類で探したい
- 不要になった大きなファイルを消して、容量を空けたい

## Artifactのパスとバージョン

ArtifactはRunごとのパス（例: `data/vowel-a.wav`、`checkpoints/step-1000/model.pt`）で管理します。同じRunの同じパスにもう一度保存すると、新しいArtifactとして保存し、そのパスで表示されるものを新しいほうに切り替えます。前のファイルは「以前のバージョン」として残り、上書きされません。

Runに属さないArtifactもあります。データセットのフォルダから作ったバージョンのファイル、［Models］や［Code］の画面からアップロードしたファイルです。

保存時に、ファイル全体のSHA-256とサイズを記録します。1件の上限は既定で200 GiBです（環境変数`MMT_ARTIFACT_MAX_BYTES`で変更できます）。

## RunのArtifactを見る

Runの詳細画面で［Artifacts］タブを開きます。左にファイルの一覧、右に選んだファイルのプレビューが表示されます。

- 一覧の上の「ルート」から始まるパンくずで、フォルダの階層を移動します
- フォルダの行には、中のファイル数と合計サイズ（例:「6件 · 125.6 KiB」）が表示されます
- フォルダが先に並び、名前の中の数字は数値として並べます（`step-9`は`step-19`より前）
- ファイルは200件ずつ読み込みます。続きは［続きを読み込む］で表示します
- 行のダウンロードのアイコンで、ファイルをダウンロードします

開いているフォルダはURLに残るので、再読み込みしたりブラウザの戻るボタンを押したりしても同じフォルダに戻ります。

プレビューの［詳細］を開くと、Artifact ID、SHA-256、保存先の名前と、同じパスの「以前のバージョン」（最大100件）が表示されます。以前のバージョンを選ぶとそのファイルをプレビューし、［最新のバージョンに戻る］で最新に戻ります。

編集権限があるユーザーには［Artifactをアップロード］が表示されます。アップロードの手順は[大きなファイルのアップロード](/data/uploads)を参照してください。

## Project全体から探す

![ProjectのArtifacts画面](/images/data-artifacts-browser.png)

サイドバーの［Artifacts］を開くと、ProjectのすべてのArtifactを検索できます。

| 条件 | 指定できる値 |
| --- | --- |
| 検索 | 保存パスに含まれる文字列（200文字まで） |
| 種類 | すべての種類、音声、画像、動画、テキスト、その他のファイル |
| Run | すべてのRun、または最近のRun（200件まで） |
| モデル | すべてのモデル、または特定のモデル。モデルを選ぶと［モデルバージョン］でも絞り込めます |
| 以前のバージョンも表示 | オンにすると、新しいファイルに置き換わった古いバージョンも表示します |

結果は「保存パス」「Run」「種類」「サイズ」「作成日時」の表で、100件ずつ表示されます。Runに属さないArtifactは「Runなし」と表示されます。検索条件はURLに残るため、URLを共有すると同じ結果を開けます。

## プレビューできる形式

| 種類 | 形式 | 表示 |
| --- | --- | --- |
| テキスト | text/plain、CSV、TSV、JSON、JSON Lines | 1 MiBまで表示します |
| 評価サンプル | jsonl、CSV | 16 MiBまでを表として50行ずつ表示します |
| 画像 | PNG、JPEG、WebP、AVIF、GIF | そのまま表示します |
| 音声 | WAV、FLAC、MP3、Ogg、Opus、M4A（AAC）、WebM | [音声ビューア](/data/audio)で波形とスペクトログラムを表示します |
| 動画 | MP4、WebM、QuickTime | ブラウザのプレーヤーで再生します |

ほかの形式と上限を超えるファイルは、「この形式はダウンロードして確認してください。」と表示されます。HTML、SVG、XMLのファイルはプレビューせず、ダウンロードとして扱います。

アップロード時にMIMEタイプが指定されていない場合は、拡張子からMIMEタイプを判定します（wav、flac、mp3、ogg、opus、m4a、aac、webm、mp4、mov、png、jpg、webp、avif、gif、csv、tsv、jsonl、txt、npy、parquet）。

評価結果は、1行に`audio`、`reference`、`prediction`、`score`を持つjsonlで保存すると、評価サンプルの表として読みやすく表示されます。

## Runどうしで比べる

Compareの画面の［Artifacts］タブでは、複数のRunの同じパスのファイルを並べて表示します。音声には［同じ位置から再生］があり、Runを切り替えても同じ再生位置から聴き比べられます。stepごとの音声・画像の比較は[メディアの記録](/tracking/media)を参照してください。

## 削除と回収

Artifactを削除できるのは、Project adminだけです。

1. Runの［Artifacts］タブで、削除するファイルを開きます
2. プレビューの右上の［⋯］（ファイルの操作）から［削除］を選びます
3. 確認ダイアログ「Artifactを削除」で［削除］を押します

削除したArtifactは、一覧、検索、ダウンロードからすぐに消えます。同じパスに以前のバージョンがあれば、それが表示されるようになります。画面から元に戻す操作はありません。

保存先にあるファイルの本体は、すぐには消えません。削除から猶予期間（既定7日、環境変数`MMT_ARTIFACT_DELETE_GRACE_DAYS`）が過ぎたあと、APIが10分ごとに回収して保存先から消します。誤って削除した場合は、猶予期間のうちに管理者に連絡してください。ファイルの本体を保存先から退避できます。

次のものから参照されているArtifactは、削除できません。先に参照している側を片付けてから削除します。

- 登録したモデルバージョンの重み（MLflowで登録したモデルのファイルを含む）
- Code画面のコードバージョン（保存したzip・tar、SingularityやApptainerのイメージ）
- データセットバージョンのファイル
- 保持しているcheckpoint、または再開に使ったcheckpoint

古いバージョンのArtifactは自動では削除しません。

MLflow SDKの`delete_artifacts`でも同じ規則で削除します。APIでは`DELETE /api/projects/<Project ID>/artifacts/<Artifact ID>`を呼びます。

## 使用量を確かめる

［プロジェクト設定］の上段にある「Artifactの使用量」に、保存先ごとの使用量が表示されます。

| 列 | 内容 |
| --- | --- |
| 保存先 | 保存先の名前 |
| 件数、容量 | 削除していないArtifactの数と合計サイズ（以前のバージョンを含む） |
| 削除待ち | 削除したが、本体をまだ回収していないもの |
| 参照されていない古いバージョン | 新しいバージョンに置き換わり、モデルバージョンやデータセットバージョンなどから参照されていないバージョン。削除の候補です |
