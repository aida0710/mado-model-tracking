# 認証方式とローカルアカウント

Mado Model Trackingのログイン方法は、API serverの環境変数`AUTH_MODE`で選びます。Authentik（SSO）だけ、ローカルアカウントだけ、両方の3つから選べます。Madoと同じ構成です。

| `AUTH_MODE` | 使えるログイン | 必須の設定 | こんなときに向いています |
| --- | --- | --- | --- |
| `local` | ローカルアカウント | なし（`OIDC_*`は読みません） | SSOが無い環境、閉じたLANで使う |
| `oidc` | Authentik（SSO）だけ | `OIDC_ISSUER_URL`、`OIDC_CLIENT_ID`、`OIDC_ALLOWED_GROUPS`、`MMT_SESSION_ENCRYPTION_KEY` | SSOへの移行を終えた本番 |
| `hybrid`（既定） | SSOとローカルアカウント | `oidc`と同じ | SSOの導入中。ローカルの管理者を緊急用のログイン経路として残す |
| `development` | 開発用ログイン | なし | ローカル開発。`NODE_ENV=production`では起動しません |

必須の設定が欠けていると、APIは足りない設定の名前だけを表示して起動しません。値はログに出しません。選んでいない方式のログイン経路は404を返します（`local`ではSSOの開始とcallback、`oidc`ではローカルアカウントのログイン）。

Authentik側の設定と、groupで権限を決める方法は[Authentik（SSO）](/admin/sso)で説明します。

## ログイン画面

ログイン画面には、`AUTH_MODE`で有効な方式だけが表示されます。

- `oidc`: SSOのボタンだけ。ボタンの表示名は`OIDC_LABEL`（既定は`Authentik`）
- `hybrid`: SSOのボタンと、その下に「またはローカルアカウント」のユーザー名・パスワード欄
- `local`: ユーザー名・パスワード欄だけ

ログインのsessionは、操作しないまま`AUTH_SESSION_IDLE_SECONDS`（既定28800秒＝8時間）が過ぎるか、ログインから`AUTH_SESSION_ABSOLUTE_SECONDS`（既定43200秒＝12時間）が過ぎた時点の早い方で切れます。idleがabsoluteより長い設定では、APIが起動しません。

## 初期管理者を作る

`local`と`hybrid`では、最初の全体管理者をAPI serverのターミナルで作ります。ユーザー名とパスワードはターミナルで入力し、コマンドの引数やログには残りません。

```sh
npm run bootstrap-admin -w @mmt/api
```

Docker Composeで動かしている場合は、APIのコンテナの中で実行します。

```sh
docker compose run --rm api npm run bootstrap-admin -w @mmt/api
```

| 表示 | 入力するもの |
| --- | --- |
| `Admin username:` | 管理者のユーザー名。小文字の英数字と`.` `_` `-`（例: `admin`） |
| `New admin password:` | 初回だけ使うパスワード（12〜1024 byte）。入力した文字は表示されません |
| `Confirm password:` | 同じパスワードをもう一度 |

`Admin ready: admin (<ユーザーID>); password change required`と表示されれば作成できています。ブラウザでログインすると「パスワードを変更」の画面になります。変更するまでは、ほかの画面とAPIは使えません（403 `password_change_required`）。

同じユーザー名が既にある場合は、そのユーザーを全体管理者・有効の状態に戻し、パスワードを置き換え、ログイン中のsessionを終了します。管理者がパスワードを忘れたときや、全体管理者が全員締め出されたときの復旧にも、このコマンドを使います。作成と再設定は監査ログに「初期管理者の作成・再設定」（`auth.bootstrap_admin`）として残ります。

## ローカルアカウントを作る

全体管理者が画面から作ります。`AUTH_MODE`に関係なく作成できますが、`oidc`ではローカルアカウントでログインできません。

![全体管理の「ユーザー」タブ](/images/admin-users.png)

1. 上部バーの［全体管理］を開き、［ユーザー］タブを選びます。
2. ［ローカルユーザーを作成］を押します。
3. 次の値を入力して保存します。

| 項目 | 入力値 |
| --- | --- |
| ユーザー名 | 小文字英数字と`.` `_` `-`、64文字まで。例: `tanaka` |
| 表示名 | 画面に出る名前。例: `田中` |
| メールアドレス（任意） | 例: `tanaka@example.com` |
| 初回パスワード | 12文字以上。［生成］でランダムな値を作れます |
| 全体管理者にする | 全体管理者にする場合だけ選ぶ |

作成したユーザーが一覧に出れば完了です。初回パスワードは本人へ安全な方法で伝えてください。初回ログインでパスワードの変更を求められます。

作成したユーザーはまだどのProjectにも入っていません。Projectの［Settings］の「Members」で追加します（[権限とRole](/admin/permissions)）。

## パスワード

ローカルアカウントのパスワードは、Argon2idでハッシュ化して保存します。12〜1024 byteで、現在と異なる値に変更できます。

- 自分で変える: 上部バーのユーザーメニューから［アカウント］→「パスワード」を開きます（`/account/password`）。変更すると、ほかのブラウザやマシンのログインは終了します。
- 忘れた: 全体管理者が［ユーザー］タブの対象の行で［パスワード再設定］を押します。一時パスワードが1回だけ表示されるので、本人へ安全な方法で伝えます。本人のsessionは終了し、次のログインで変更を求められます。
- SSOだけのユーザーは、このアプリにパスワードを持ちません。パスワードはAuthentikで管理します。

ログインと現在のパスワードの確認には回数の上限があります。上限を超えると「試行回数の上限に達しました」と表示され、APIは429と`Retry-After`を返します。

| 対象 | 上限 |
| --- | --- |
| 同じ接続元からのログイン | 1分に30回 |
| 同じユーザー名へのログインの失敗 | 15分に10回 |
| パスワード変更時の現在のパスワードの確認 | 同じユーザーで15分に10回 |

回数はAPIのプロセスのメモリで数えているので、APIを再起動すると元に戻ります。存在しないユーザー名、誤ったパスワード、無効化したユーザーは、どれも同じ「ユーザー名またはパスワードが正しくありません」になります。

## ユーザーを止める・戻す

退職や異動でユーザーを止めるときは、全体管理者が［ユーザー］タブで操作します。

1. 対象の行で［無効化］を押し、確認のダイアログで確定します。ログイン中のsessionは直ちに終了し、そのユーザーのAPI token（MLflow互換APIを含む）も次の要求から401になります。
2. SSOのユーザーは、Authentik側でもgroupから外します。外さずに有効化すると、次のログインでgroupから決まる全体管理者の判定に戻ります。
3. 戻すときは同じ行で［有効化］を押します。API tokenは再び使えますが、終了したsessionは戻りません。もう一度ログインが必要です。

ユーザーは削除できません。Runやモデル版の作成者の記録を保つためです。最後の有効な全体管理者は、無効化も管理者を外すこともできません（409 `last_global_admin`）。先に別の全体管理者を用意してください。

SSOのユーザーの全体管理者の判定と表示名はAuthentikが正本なので、画面からは変えられません。［全体管理者］の欄に「Authentikのgroupが正本」と表示されます。

## SSOへ移行する

ローカルアカウントで運用していた環境をSSOへ移すときは、`hybrid`を経由します。

1. `AUTH_MODE=hybrid`と[Authentikの設定](/admin/sso)を`.env`に入れ、`npm run db:migrate`を実行してからAPIを再起動します。
2. `bootstrap-admin`でローカルの管理者を作り、パスワードを変更しておきます。
3. 管理者と一般のメンバーがSSOでログインし、全体管理者の判定とProjectの権限が正しいことを確かめます。
4. 確かめられたら`AUTH_MODE=oidc`に変えて再起動します。ローカルアカウントのログインは404になります。

Authentikが止まってログインできなくなったときは、`AUTH_MODE=hybrid`へ戻して再起動すると、ローカルの管理者でログインできます。
